# TAOM Mods

The website for two add-on mods for TAOM (Tales from the Age of Men) on Mount & Blade II: Bannerlord 1.5.7, by MinimalCash63:

- TAOM AIO Compatibility Patch: https://github.com/MinimalCash63/TAOM-AIO-Compat
- TAOM Extra Loading Screens: https://github.com/MinimalCash63/TAOM-Extra-Loading-Screens

Site: https://minimalcash63.github.io/TAOM-MODS/

This repository only holds the website. Download the mods from their own pages above.

The pictures belong to their artists (named under each one on the page). Fonts: IM Fell English, IM Fell English SC and EB Garamond, SIL Open Font License 1.1 (licence texts in `assets/fonts/`).
